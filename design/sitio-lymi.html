EL PROBLEMA

Nadie publica contra qué compara.

«Ahorra un 80%» no es falsable: quien lo dice elige la línea base que le conviene. Y «es local» suele significar que tus documentos viajan por la API de otro. Aquí la línea base es código de este repositorio, y la afirmación se falsa con una curva: la misma tarea en repos de 1k, 10k, 100k y 1M de líneas. Plana, se sostiene. Creciente, es falsa y se publica como falsa.

CÓMO — DE MAYOR A MENOR EFECTO
01

El índice nunca entra al contexto

El mapa del proyecto vive en SQLite y en el servidor de lenguaje. El modelo lo consulta; jamás lo recibe entero. Volcar el grafo al prompt te devuelve a O(N) con estética bonita.

02

Símbolos, no archivos

La función pedida y sus referencias, no las 900 líneas que la rodean.

03

El volumen lo absorbe tu GPU

Clasificar, resumir y escribir memoria corre en un modelo local de 4B. Al caro llega solo lo destilado.

04

Presupuesto de contexto duro

Techo fijo de tokens: para meter algo nuevo hay que desalojar lo viejo. Acotado por construcción, no por esperanza.

LOS TRES RIESGOS DE UN AGENTE CON CONTROL DEL PC

Por eso se suelen aislar en una máquina desechable. lymi vive en la tuya.

Rompe el sistema

Propone, un ejecutor acotado aplica y todo se deshace: plan antes de actuar, rutas del sistema vetadas, diario de deshacer, código en worktrees y sandbox para lo no confiable.

Olvida todo

La memoria vive fuera del modelo, en markdown que abres con Obsidian: la escribe el modelo local, se recupera acotada y la edición humana siempre gana.

La API lee tus datos

Cada dato tiene etiqueta. Lo confidencial lo lee tu GPU, y un único gateway bloquea, redacta y registra lo que sale, por hash, nunca el contenido.

LO QUE NO AFIRMAMOS
×

Que sea «local» si usa una API remota

Si el dato salió, salió. Queda registrado el destino y el hash, nunca el contenido.

×

Que el debate entre agentes ahorre tokens

Es un multiplicador de costo. Entra solo si la medición demuestra que cambia el resultado.

×

Que los subagentes bajen el consumo total

Bajan el del hilo principal; el total puede subir. Se mide de punta a punta.

×

Que haya ahorro en tareas de barrido

Renombrar en todo el código toca todo por definición. Ahí los tokens remotos crecen con los hallazgos, no con el repo. Pero crecen.
